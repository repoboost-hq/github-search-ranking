# Glossary

**Aged account** - a GitHub account with years of real public activity, used for delivery instead of a fresh registration.

**Pacing** - spreading actions across a delivery window so growth looks organic.

**Star velocity** - the rate at which a repository gains stars over time. GitHub Trending ranks momentum, not totals.

**No-drop guarantee** - if any delivered action disappears, it is replaced free.

**Balanced package** - stars arriving together with forks, watches and followers.
