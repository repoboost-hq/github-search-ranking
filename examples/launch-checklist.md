# Launch checklist

A practical pre-launch list for a repository that should look adopted from day one.

## Before launch

- [ ] Repository name matches what people search for
- [ ] About description is one clear, keyword-front-loaded line
- [ ] 6-10 relevant topics set
- [ ] README answers what it does, who it is for, and how to start
- [ ] LICENSE, CONTRIBUTING and issue templates in place

## Launch day

- [ ] Post in the right window (12:00-17:00 UTC works best for HN front page)
- [ ] Share in two or three relevant communities, not ten
- [ ] Watch the first hour and reply to every comment

## First week

- [ ] Keep momentum: small updates, quick responses
- [ ] Track which channel sent the best traffic
